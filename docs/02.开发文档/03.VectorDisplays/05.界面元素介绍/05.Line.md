[top.mrxiaom.hologram.vector.displays.ui.widget.Line](https://javadoc.io/doc/top.mrxiaom.hologram/VectorDisplays-API/latest/top/mrxiaom/hologram/vector/displays/ui/widget/Line.html)

线条是一个类似[标签](/elopers/vd/elements/label)的简单元素，可以设置以下属性，来将带有多个空格的标签给拉伸成一个线条：

| 属性 | 描述 |
| --- | --- |
| `pos1`, `x1`, `y1` | 第一个点在平面上的坐标 |
| `pos2`, `x2`, `y2` | 第二个点在平面上的坐标 |
| `thickness` | 线条宽度 |

一个简单用例：
```java
terminal.addElement(new Line("line1"), e -> {
    e.setBackgroundColor(0xFFFF00FF);
    e.setPos1(-20, -10);
    e.setPos2(0, 10);
    e.setThickness(0.2);
    e.setFullBrightness();
});
```
