[top.mrxiaom.hologram.vector.displays.ui.widget.Label](https://javadoc.io/doc/top.mrxiaom.hologram/VectorDisplays-API/latest/top/mrxiaom/hologram/vector/displays/ui/widget/Label.html)

这是一个标签元素，使用单个文本展示实体构成。基于 TextElement，可以查阅[界面通用元素](/elopers/vd/elements/common)文档来查看基础通用的属性。可以直接通过 `new` 来实例化一个标签，具体用法请见上方 Javadoc 相关文档。

Label 额外可用的属性只有一个 `text`，可以使用字符串来按 MiniMessage 解析，也可以使用 Component 来使用更精确的富文本格式。

一个简单用例：
```java
terminal.addElement(new Label("label1"), e -> {
    e.setText("<#FF0000>测试");
    e.setScale(0.25f);
    e.setPos(10, 0);
    e.setFullBrightness();
});
```
